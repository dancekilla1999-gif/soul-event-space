# Soul Event Space

Одностраничная презентация событийной площадки **Soul** — зелёного «оазиса» на 550 кв.м в центре Москвы.

Статичный сайт: чистые HTML/CSS/JS, без сборки и зависимостей — открывается прямо из `index.html`.

## Структура

```
index.html      — вся презентация (6 слайдов)
images/         — фотографии зала
```

## Разработка

Файл самодостаточный — просто откройте `index.html` в браузере, либо поднимите любой статический сервер:

```bash
python3 -m http.server 8080
```

## Хостинг

В репозитории настроен GitHub Pages (деплой из ветки `main`, GitHub Actions).
После первого пуша сайт будет доступен по адресу:

`https://dancekilla1999-gif.github.io/soul-event-space/`

(включить можно в Settings → Pages → Source: GitHub Actions, если ещё не включено).

## Что нужно доделать

- **Слайд 5** (кальяны / коктейльный бар / фотозона блюд) — сейчас там стильные
  CSS-заглушки вместо фото: пришлите реальные снимки — вставим.
- **Слайд 6** (контакты) — телефон, e-mail, адрес и соцсети сейчас помечены
  как плейсхолдеры (пунктирная рамка) — впишите реальные данные в `index.html`
  в секции `#s6 .contact-fields`.
