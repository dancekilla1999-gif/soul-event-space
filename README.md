# Soul Event Space

Одностраничная презентация событийной площадки **Soul** — зелёного «оазиса» на 550 кв.м в центре Москвы.

Статичный сайт: чистые HTML/CSS/JS, без сборки и зависимостей — открывается прямо из `index.html`.

## Структура

```
index.html      — вся презентация (6 слайдов)
images/         — фотографии зала
```

## Разработка

Файл самодостаточный — просто откройте `index.html` в браузере, либо поднимите любой статический сервер:

```bash
python3 -m http.server 8080
```

## Хостинг

Сайт опубликован через GitHub Pages из ветки `gh-pages`.
При каждом пуше в `main` workflow пересобирает эту ветку автоматически.
Сайт доступен по адресу:

`https://dancekilla1999-gif.github.io/soul-event-space/`

Ветку `gh-pages` править вручную не нужно — она перезаписывается workflow.
